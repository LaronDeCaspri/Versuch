MethodHow a project runs

DMAIC: five phases, each closed with a review

Every phase ends with an exit review with the sponsor. Decisions are based on data, not on assumptions.

D
Define

Project charter, SIPOC, critical-to-quality tree, cost of poor quality.

M
Measure

Data collection plan, measurement system analysis, baseline capability.

A
Analyse

Ishikawa, hypothesis tests, ANOVA and regression to confirm root causes.

I
Improve

Design of experiments, error proofing, piloting of the solution.

C
Control

Control charts, control plan and process audits to sustain the gain.
